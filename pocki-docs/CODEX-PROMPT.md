# Prompt para o Codex

Implemente o projeto Pocki descrito nos arquivos `README.md`, `GAME-DESIGN.md` e `TECH-SPEC.md` deste diretório.

Objetivo: entregar um jogo completo e pequeno, inspirado no Tamagotchi P1, com visual retrô modernizado, evolução por estágios, passagem do tempo real e ações clássicas. Use exclusivamente HTML, CSS e JavaScript puro em produção. Não use frameworks, backend, bundler, dependências de produção ou serviços externos.

Leia os três documentos integralmente antes de escrever código. Em caso de conflito, priorize: decisões aprovadas em README, regras em GAME-DESIGN e critérios técnicos em TECH-SPEC. Se encontrar ambiguidade que altere o escopo, apresente uma pergunta objetiva; para detalhes triviais, escolha a solução mais simples e documente.

Implemente em quatro passos: (1) lógica pura e testes de tempo/estados; (2) interface responsiva e controles A/B/C; (3) persistência, áudio e integração; (4) execução de testes e revisão. Não crie recursos fora do escopo, nem replique sprites ou marcas de terceiros.

Ao concluir, apresente resumo dos arquivos criados, instruções exatas para executar localmente, testes executados e limitações conhecidas. Não declare sucesso para testes que não executou.

Critério de pronto: todos os 15 testes de aceitação do TECH-SPEC devem estar satisfeitos ou explicitamente identificados como pendentes.
